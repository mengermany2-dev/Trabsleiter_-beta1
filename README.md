# Game Translator

Android-приложение: плавающая кнопка поверх игр, которая переводит английский текст на экране на русский.
Распознавание (Google ML Kit OCR) и перевод (ML Kit Translate) работают на устройстве. Интернет нужен только один раз, чтобы скачать языковые модели.

## Как получить APK без Android Studio

1. Зарегистрируйтесь на https://github.com (бесплатно) и нажмите **New repository**. Название любое, например `GameTranslator`.
2. Распакуйте архив и загрузите **все файлы и папки** в репозиторий: **Add file → Upload files**, перетащите содержимое папки целиком.
   - Важно, чтобы загрузилась скрытая папка `.github` (в ней файл `workflows/build.yml`). Если она не загрузилась, создайте файл вручную: **Add file → Create new file**, в поле имени введите `.github/workflows/build.yml` и вставьте содержимое из архива.
3. Откройте вкладку **Actions**. Сборка запустится сама после загрузки (2–5 минут). Если не запустилась, выберите **Build APK → Run workflow**.
4. Когда рядом с запуском появится зелёная галочка, откройте его и внизу в разделе **Artifacts** скачайте `GameTranslator-apk`. Внутри zip лежит `app-debug.apk`.
5. Установите APK на телефон (разрешите установку из неизвестных источников).

Если сборка закончилась красным крестиком, откройте неудачный запуск, скопируйте последние строки лога с ошибкой и пришлите их мне.

## Первый запуск

1. Выдайте разрешение «Поверх других приложений».
2. Нажмите «Скачать языковые модели» (один раз, нужен интернет).
3. Нажмите «Запустить плавающую кнопку» и в системном окне выберите **«Весь экран»** (не «Одно приложение»).
4. Откройте игру. Нажмите кнопку A→Я, выберите «Весь экран» или «Область».

На некоторых оболочках (Xiaomi, Huawei, Samsung и др.) может понадобиться отдельно разрешить «Всплывающие окна» и отключить экономию батареи для приложения.

## Ограничения

- Если игра запрещает скриншоты (защита FLAG_SECURE), кадр будет чёрным.
- OCR распознаёт латиницу. Сильно стилизованные шрифты могут читаться хуже.
- Перевод показывается поверх экрана и не следит за игрой: после смены текста нажмите перевод ещё раз.
